# NP Practice Resource

BC-first clinical reference and source index for nurse practitioners.

This repository stores the content and workflow for NP Practice Resource, a structured clinical knowledge site for NPs. It organizes current BC and Canadian guidance into a reviewable, source-based framework for point-of-care use.

## Disclaimer

This website is for educational purposes only and is not to be used to make medical decisions.

- Medical decisions should be made only with the guidance of a licensed medical professional.
- Medical professionals should use their own clinical judgement when assessing, appraising and applying all resources and material.

## Repository structure

- `docs/` — website content
- `00 Inbox/` — unprocessed links and resources
- `01 Projects/` — active work
- `02 Areas/` — topic areas and workflows
- `03 Resources/` — templates and reference material
- `04 Archive/` — historical notes and older files
- `.github/` — GitHub workflows and automation
- `scripts/` — helper scripts
- `NPPR-FRAMEWORK.md` — project framework, governance, and roadmap
- `FRONTMATTER.md` — page metadata and frontmatter standards
- `CLAUDE.md` — project workflow and AI-assisted process notes
- `LICENSE` — project license

## Purpose

The project aims to provide a clear, consistent, evidence-based structure for clinical guidance, with:
- BC-first coverage
- source metadata and review dates
- organized conditions, assessments, prescribing, and practice pages
- a standard workflow for maintaining current sources

## Notes

This repo is designed to support a public clinical website while maintaining a transparent, source-based editorial process.
